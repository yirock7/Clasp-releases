Clasp 0.6.0 is a look-and-feel release: a new app icon and a soft coloured edge on Clasp's windows. Nothing about how Clasp works has changed. It is still a preview release, and the source code is public.

## New

- **A new app icon.** It shows the charging case from Clasp's own artwork, lid open with the earbuds peeking out, on dark frosted glass with a soft colour edge. At the smallest sizes (such as the taskbar) it shows the closed case with its green light, so it stays readable. The taskbar, Start menu, installer, notifications, Settings and the README all use it. The tray icon is unchanged: it is still the silhouette of your device, tinted by battery.
- **A soft coloured glass edge on Clasp's windows.** The flyout, Settings and the welcome guide now have an edge that matches the icon. It glows briefly when a window opens, is softer on the light theme, and is off in High Contrast and when transparency effects are off.

If you pinned Clasp to the taskbar, its icon updates by itself after the update. Windows sometimes keeps showing the old icon for a little while; if it does, it will refresh on its own, or after you sign out and back in.

## Installing

Download `Clasp-0.6.0-win-x64-setup.exe` and its `.sig` file into the same folder, and **check the signature first** (steps in the README). Windows will probably show a "Windows protected your PC" box because the installer is not code-signed yet; after the signature check passes, choose **More info**, then **Run anyway**. If you already have Clasp, click **Update** in Settings instead.
