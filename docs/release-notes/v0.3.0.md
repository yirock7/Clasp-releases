Clasp 0.3.0 is the first release with the source code public. It also brings a new tray icon and some security hardening.

## What's new

- **A tray icon that shows your device.** It draws the silhouette of your connected device, or the last device you used, dimmed, when it is not connected. Its colour shows the battery: amber when low, red at your low-battery level, green while charging. There is no number on the icon; hover for the exact percentage, or click for full details.
- **Clasp is open source** under the GPL-3.0. The source is in this repository, and the projects it builds on are credited in [THIRD-PARTY-NOTICES.md](https://github.com/yirock7/Clasp-releases/blob/main/THIRD-PARTY-NOTICES.md).
- **A signature check for manual installs.** A small script checks the installer's signature before you run it. See [the install steps](https://github.com/yirock7/Clasp-releases#download-and-install).

## Safer

- Downloads can now be checked with a signature, not just a checksum.
- Clasp limits how many Bluetooth broadcasts it looks at per second, so a flood of fake signals cannot slow it down.
- A nearby device faking your AirPods can no longer trigger a low-battery alert, and low-battery alerts now have a cooldown. Clasp now also needs stronger evidence that a broadcast is really yours (it must have seen your AirPods connect or disconnect while it was running), so you may get fewer alerts than before, and each alert is followed by a 2-hour quiet period.
- The interface shows only the latest state when many updates arrive at once.

Nothing here is known to have affected anyone.

## Changed

- Demo mode and screenshots show the battery in 10% steps, like real broadcasts.
- The documentation was rewritten to be easier to read.

## Installing

Download `Clasp-0.3.0-win-x64-setup.exe` and its `.sig` file into the same folder, and **check the signature first** (steps in the README). Windows will probably show a "Windows protected your PC" box because the installer is not code-signed yet; after the signature check passes, choose **More info**, then **Run anyway**. If you already have Clasp, click **Update** in Settings instead.
