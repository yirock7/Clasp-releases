Clasp 0.5.0 is mostly tidying up. The program has a new name, and a few things you could see in 0.4.x are cleaner. It is still a preview release, and the source code is public.

## Changed

- **The program is now called `Clasp.exe`, and its data folder is `%LOCALAPPDATA%\Clasp`.** Both used to carry an older internal name (`AppleDeviceHub`). **The update moves your settings, battery history and log to the new folder for you**, the first time the new version starts. Your settings are never deleted before they are safely copied. Your "Start Clasp when I sign in" setting and the `clasp:` link setting carry over, and Setup and the app repair those entries after the rename. If you pinned the old `AppleDeviceHub.exe` to the taskbar, **pin Clasp again from the Start menu**, because the old shortcut points at a file that no longer exists.
- **Starting `Clasp.exe` directly now uses real Bluetooth.** It no longer shows made-up Demo battery numbers. Demo mode now needs `--transport=demo`. The Start menu, desktop and sign-in entries are unchanged.

## New

- **If Clasp closes unexpectedly, it tells you the next time it starts.** A notification says so and shows where `hub.log` is. The log records what kind of error it was, not its message.
- **The project is ready for visitors.** The README says plainly that Clasp is a preview, there is a form for reporting how it works with your AirPods or Beats, and `docs/TOOLCHAIN.md` lists what you need to build the installer.

## Fixed

- **`hub.log` no longer contains device names or error messages.** It never contained Bluetooth addresses; it now records errors by type only.

## Behind the scenes

- The app's on-screen text now lives in resource files, which prepares the way for translations. Nothing looks different.

## Installing

Download `Clasp-0.5.0-win-x64-setup.exe` and its `.sig` file into the same folder, and **check the signature first** (steps in the README). Windows will probably show a "Windows protected your PC" box because the installer is not code-signed yet; after the signature check passes, choose **More info**, then **Run anyway**. If you already have Clasp, click **Update** in Settings instead.
